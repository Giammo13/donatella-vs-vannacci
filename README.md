# Cose che farebbe Donatella piuttosto che votare Vannacci

Sito statico a card sequenziali. Nessuna build necessaria: è un singolo `index.html` con HTML/CSS/JS vanilla.

## Modificare le frasi

Apri `index.html`, cerca la costante `listaDonatella` (verso la fine del file, dentro il tag `<script>`) e sostituisci l'elenco con le tue frasi.

## Provare in locale

Basta aprire `index.html` nel browser (doppio click), oppure con un server locale:

```
npx serve .
```
